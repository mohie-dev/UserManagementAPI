# UserManagementAPI

An ASP.NET Core Web API developed for TechHive Solutions to manage user records for internal HR and IT tools.

## Features

- Retrieve all users.
- Retrieve a user by ID.
- Create new users.
- Update existing users.
- Delete users.
- Middleware implementation and API request handling.
- API testing using Postman.
- Development assistance using Microsoft Copilot.

## Technologies

- C#
- ASP.NET Core Web API
- REST API
- Swagger / OpenAPI
- Postman
- Microsoft Copilot

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /api/users | Retrieve all users |
| GET | /api/users/{id} | Retrieve a user |
| POST | /api/users | Create a user |
| PUT | /api/users/{id} | Update a user |
| DELETE | /api/users/{id} | Delete a user |

## AI Assistance

Microsoft Copilot was used to assist with scaffolding, generating API endpoints, debugging, and implementing middleware. Generated suggestions were reviewed and tested to validate functionality.

## Project Purpose

This project is part of the Back-End Development with .NET course on Coursera, demonstrating practical API development, debugging, middleware implementation, and AI-assisted software development.
